# NGINX Security & Reverse Proxy Lab

## Overview
Hands-on lab demonstrating NGINX reverse-proxy configuration,
TLS termination, and rate limiting.

## Technologies
- Linux
- NGINX
- HTTP/HTTPS
- TLS

## Objectives
- Configure NGINX as a reverse proxy
- Configure TLS termination
- Implement request rate limiting
- Practice troubleshooting web and network configuration

## Skills Demonstrated
- Linux system configuration
- Networking fundamentals
- Web service troubleshooting
- Security configuration
- Technical documentation
